# Study materials

Put the stimulus and quiz materials here so the study is reproducible:

- `videos.md`: title, URL, length, and source for Video A and Video B
- `ai_prompt.md`: the exact ChatGPT prompt, model name/version, and date used to
  generate the AI summaries (and the generated summaries themselves)
- `quiz_items.md`: the full text of each quiz question and its answer options,
  marking each as factual or conceptual (must match `data/raw/answer_key.csv`)
- `consent_and_instructions.md`: participant script and consent text
